# ZainSaham Frontend

React 19, Vite 8, Tailwind CSS 4, dan Lightweight Charts.

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Backend harus sudah berjalan di port 8000. Lihat [README utama](../README.md).

| Perintah | Kegunaan |
| --- | --- |
| `npm run dev` | Server development |
| `npm run lint` | Cek kode dengan Oxlint |
| `npm run build` | Build ke folder `dist` |
| `npm run preview` | Lihat hasil build |
